Plain-English Dictionary

💡 Cybersecurity Jargon Buster (Zero-Tech Definitions)

13 foundational concepts translated into simple everyday analogies:

IP Address
Internet Protocol Address

A computer's digital home address so internet mail and data know where to go.

Port
TCP/UDP Network Port

Numbered doors on a building (1 to 65,535). Port 80/443 is the front door; Port 22/3389 is the back server door.

Domain Name
Fully Qualified Domain Name (FQDN)

Your company's nameplate on the internet (e.g. monitorix.elsea.co.in) instead of remembering confusing numbers.

DNS
Domain Name System

The internet's phonebook that translates nameplates (monitorix.elsea.co.in) into computer numbers (IP addresses).

CNAME
Canonical Name Alias

A digital forwarding address pointing one domain name to another service (like an S3 bucket or GitHub page).

Subdomain Takeover
Orphaned CNAME Exploitation

Like moving out of an apartment but forgetting to cancel mail forwarding, allowing a stranger to move in and read your mail.

Ransomware
Cryptoviral Extortion Malware

Digital kidnappers who sneak into a computer, lock all your files with an unbreakable password, and demand millions to unlock them.

mTLS 1.3
Mutual Transport Layer Security

Both the computer and the server show digital government passports to each other before talking, so nobody can eavesdrop.

Zero Trust
Continuous Verification Model

'Never trust, always verify.' Even if you work at the company and are sitting at your desk, the system checks your ID every time.

EDR / XDR
Extended Detection & Response

A digital police force and surveillance camera network watching every computer, server, and network cable 24/7.

SOAR
Security Orchestration & Response

An automated fire sprinkler system that immediately sprays water and locks fire doors in 0.24 seconds when smoke is detected.

SIEM
Security Information & Event Mgmt

A digital warehouse that collects millions of security logs every second and searches for suspicious patterns.

CVE
Common Vulnerabilities & Exposures

The global catalog of known bugs and unlocked doors in software that hackers try to break through.

Tier 1 analyst receives P1 alert in SOC Work Queue (/soc/queue). Analyst clicks 'View Process Lineage' to identify the parent process (e.g. word.exe -> cmd.exe -> crypt.exe) and checks the 3D globe for other infected hosts.

Minute 05-15
Blast Radius Quarantine & Credential Revocation

Analyst executes SOAR Playbook 'Ransomware Fleet Containment'. Monitorix invokes Active Directory API to invalidate user Kerberos tickets and lock compromised accounts across the enterprise.

Minute 15-30
Clean-State Recovery & Post-Mortem

Analyst verifies immutable shadow copies and MinIO backups. Forensic memory snapshots are locked in the Evidence Vault for legal review. Host is reprovisioned and returned to service.

Target: Corporate DNS Records & Cloud Providers (AWS S3, GitHub, Azure)

Automated Drift Detection

EASM engine identifies a CNAME alias resolving to a 404 NXDOMAIN target at an external cloud vendor.

Risk Prioritization & Cloudflare API Null-Route

Monitorix flags the asset as High Risk (CVSS 9.8). The SOAR engine calls Cloudflare API to temporarily pause or null-route the dangling DNS record.

Minute 03-10
Asset Reclamation & Cloud Verification

DevOps team reclaims the orphaned bucket or deletes the DNS record permanently from the master DNS zone.

Minute 10-15
Perimeter Rescan & Audit Confirmation

EASM triggers an immediate targeted rescan to verify that the domain no longer resolves to an unclaimed namespace.

SOP 03: Impossible Travel & Compromised Admin Credential

Geodesic Velocity Violation Triggered

Security Protocol

🔑 The Zero-Trust SDK Key Handshake Protocol

To eliminate credential leakage in reverse proxies and application logs, Monitorix prohibits direct long-lived API key usage on public endpoints. Instead, external applications execute a Zero-Trust Handshake:

  1. Key Issuance: Tenant Administrator generates a scoped key starting with mk_... in Developer Keys (Settings or /developers).
  2. Handshake Call: Application backend calls POST /api/auth/sdk-handshake passing { "sdk_key": "mk_..." }.
  3. Cryptographic Verification: Backend verifies the SHA-256 token hash, enforces IP Whitelist restrictions, and drops the raw key from memory.
  4. Session JWT Issued: Returns a cryptographically signed Session JWT (15-60 min validity) containing the tenant enclave context (tenantId).
  5. Invoking Protected APIs: Client passes Authorization: Bearer <session_jwt> to access any of the 715+ REST endpoints. Validated identities are cached in Redis with a 60-second fast-path TTL.
